- `shared/src/config.ts`: добавить `export const CAR_REVERSE_SPEED = 6;`
- `server/src/systems/vehicles.ts:34-51` — скорость сделать знаковой:
  - `up`: `speed = min(CAR_MAX_SPEED, speed + CAR_ACCEL*dt)` (работает и из минуса — тормозит реверс).
  - `down`: если `speed > 0` — тормоз `max(0, speed - CAR_BRAKE*dt)`; иначе — реверс `max(-CAR_REVERSE_SPEED, speed - CAR_ACCEL*dt)`.
  - без ввода: drag к нулю по модулю (сейчас `Math.max(0, ...)` — не трогает отрицательную).
  - поворот: agility считать от `|speed|`, направление поворота умножить на `Math.sign(speed)` (при реверсе руль инвертируется).
  - движение: условие `speed > 0` заменить на `!== 0` (знаковая скорость сама даёт задний ход в `nx/nz`).
- Тест в `server/test/vehicles.test.ts`: с места держим `down` → скорость отрицательная, упирается в `-CAR_REVERSE_SPEED`, машина едет назад (`z > 0` при rotY=0). Запуск: `npm test` из корня.
