# Этап «Чат» — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Общий чат для всего сервера: лента слева внизу + поле ввода по Enter, история последних 20 сообщений по запросу, серверная валидация (длина + антиспам).

**Architecture:** Чат — события, не состояние: ходит сообщениями комнаты (`'chat'`, `'chatHistoryReq'`/`'chatHistory'`), не попадает в схему Colyseus. Сервер: чистая `tryChat` (юнит-тестируема) + тонкая проводка в CityRoom с ринг-буфером в памяти. Клиент: DOM-лента в HUD, ввод через `#chatInput` с `exitPointerLock` и typing-guard в InputController.

**Tech Stack:** Colyseus 0.16, Vitest, Three.js + Vite.

**Spec:** `docs/superpowers/specs/2026-07-19-chat-design.md` (утверждена).

## Global Constraints

- Константы только в `shared/src/config.ts`: `CHAT_MAX_LEN = 120`, `CHAT_COOLDOWN_MS = 1500`, `CHAT_HISTORY = 20`.
- Валидация серверная: `trim`, длина 1..`CHAT_MAX_LEN`, `now - lastChatAt >= CHAT_COOLDOWN_MS`; невалидное молча игнорируется.
- Чат доступен в любом `mode` (foot/car/jail/dead) — проверок режима НЕТ.
- Сообщение broadcast: `{ from, text, t }` (`t = state.serverTime`); своё сообщение рендерится серверным эхом, локального эха нет.
- Вставка в DOM только через `textContent` (XSS невозможен).
- **Уточнение спеки (принято при планировании):** история — pull-модель `'chatHistoryReq'` → `'chatHistory'`, а не push в `onJoin`: клиент регистрирует `onMessage` после входа (в `bootGame` после ожидания первого снапшота), push-пакет из `onJoin` дропнулся бы до подписки. Интент спеки (новичок видит историю при входе) сохранён: клиент шлёт запрос из конструктора UI.
- Коммиты на русском, conventional-style; работа на main (принято в репо).

Создать `server/src/systems/chat.ts`:

```ts
import { CHAT_MAX_LEN, CHAT_COOLDOWN_MS } from '@mmo/shared';
import type { GameState } from '../schema/GameState.js';
import type { Runtime } from '../runtime.js';

export interface ChatMessage { from: string; text: string; t: number }

export function tryChat(
  state: GameState,
  runtimes: Map<string, Runtime>,
  playerId: string,
  text: unknown,
  now: number,
): ChatMessage | null {
  const p = state.players.get(playerId);
  const rt = runtimes.get(playerId);
  if (!p || !rt) return null;
  const trimmed = typeof text === 'string' ? text.trim() : '';
  if (trimmed.length === 0 || trimmed.length > CHAT_MAX_LEN) return null;
  if (now - rt.lastChatAt < CHAT_COOLDOWN_MS) return null;
  rt.lastChatAt = now;
  return { from: p.name, text: trimmed, t: state.serverTime };
}
```

      if (!msg) return;
