# Браузерная MMO «Real Life MVP» — дизайн-документ

Дата: 2026-07-17
Статус: утверждён пользователем (по секциям)

## 1. Обзор

Браузерная 3D MMO на 100 игроков в стиле «реальной жизни» на маленькой городской карте. MVP включает все четыре ключевые системы в упрощённом виде: аренда недвижимости, кулачный бой, езда на машинах с аркадной физикой, роль полиции для игроков.

**Цель первого этапа:** играбельный MVP, где все системы работают вместе в одной комнате на 100 игроков.

## 2. Решения, принятые на брейншторме

| Вопрос | Решение |
|---|---|
| Scope первого этапа | MVP: все системы упрощённо |
| Стек | Colyseus (сервер) + Three.js (клиент) |
| Камера | От третьего лица |
| Бой | Только ближний бой (кулаки) |
| Полиция | Игроки-полицейские |
| Экономика | Работы (доставка) + зарплата копам |
| Недвижимость | Аренда = точка респауна + сейф |
| Город | Маленькая ручная карта из примитивов |
| Персистентность | SQLite |
| Сетевая архитектура | Сервер-авторитет (server-authoritative) |

## 3. Архитектура

**Стек:** Node.js + Colyseus, Three.js + Vite, SQLite (`better-sqlite3`), TypeScript везде.

**Структура монорепо:**

```
mmo2game/
├── server/          # Colyseus-сервер (авторитетный)
│   ├── rooms/       # CityRoom — одна комната на 100 игроков
│   ├── systems/     # Логика: движение, бой, экономика, полиция
│   ├── schema/      # Colyseus-схемы состояния (sync с клиентами)
│   └── db/          # SQLite: игроки, деньги, аренда
├── client/          # Three.js + Vite
│   ├── render/      # Сцена, камера от 3-го лица, модели из примитивов
│   ├── net/         # Подключение к Colyseus, интерполяция чужих позиций
│   └── input/       # Управление (WASD, мышь, вход/выход из машины)
└── shared/          # Общие константы и типы (карта города, цены, конфиг)
```

**Поток игры:**

1. Клиент подключается → выбор ника и роли (гражданин/полицейский) → спавн в городе.
2. Клиент шлёт ввод (клавиши) на сервер 20 раз/сек; сервер считает физику и состояние, рассылает дельты всем клиентам.
3. Чужие игроки и машины на клиенте интерполируются между снапшотами — плавное движение.
4. Деньги и аренда пишутся в SQLite при изменениях (дебаунс 5 сек) и при дисконнекте; загружаются при входе.

**Масштаб до 100 игроков:** одна Colyseus-комната, тик 20 Гц, схемы рассылают только дельты. Нагрузочный тест — headless-боты через `@colyseus/loadtest`.

## 4. Игровые системы

### 4.1 Персонаж и движение

- Капсула, скорость ходьбы ~5 м/с, бег на Shift, гравитация.
- Коллизии со зданиями и границами карты — AABB (общий конфиг на сервере и клиенте).
- Управление WASD + мышь, камера от третьего лица за спиной.

### 4.2 Машины

- ~15 припаркованных машин по городу. Машины в MVP неуничтожимы; брошенная машина (5 минут без водителя) возвращается на ближайшую парковку.
- `E` рядом с машиной — сесть за руль / выйти. Чужие машины можно угнать (это «нарушение»).
- Аркадная физика (на сервере): газ/тормоз меняют скорость 0–20 м/с; руль поворачивает, радиус поворота растёт со скоростью; сопротивление качению; столкновение со зданием = остановка.
- Водитель шлёт тот же ввод; сервер считает машину как сущность с привязанным игроком.

### 4.3 Бой

- Только кулаки: клик мыши, цель в радиусе 2 м перед собой, урон 20 HP.
- 100 HP, медленная регенерация вне боя.
- Смерть: потеря 50% наличных (деньги сгорают, не выпадают), респаун в своей квартире (или в больнице, если квартиры нет).
- Убийство гражданина или копа → статус «розыск» на 3 минуты.

### 4.4 Полиция

- Роль выбирается при входе, лимит ~20 копов.
- Коп видит маркеры над игроками в розыске.
- Арест: коп находится рядом с розыскным 3 секунды → тот в тюрьму на 2 минуты и теряет 25% наличных (сгорают).
- Зарплата: 50$ каждые 5 минут + бонус за арест.
- Коп в розыске не может арестовывать.

### 4.5 Экономика

- Старт: 500$.
- Работа доставки (только на машине): взять груз в точке А (склад) → довезти до точки Б за 3 минуты → +100$.
- Зарплата копам: 50$/5 мин.
- Наличные при себе рискованны (теряются при смерти/аресте) — мотивация снимать жильё и класть деньги в сейф.

### 4.6 Недвижимость

- ~10 квартир в разных зданиях, аренда 100$ за реальный час нахождения онлайн, автоматическое списание.
- Аренда даёт: точку респауна + сейф (деньги в сейфе не теряются при смерти/аресте, лимит 5000$).
- Не хватило денег на списание → квартира освобождается.
- Интерьеров нет: аренда и сейф — через UI у двери квартиры.

## 5. Город и карта

- Размер 400×400 м, сетка улиц 4×4 квартала, дороги с разметкой, тротуары.
- Центр: больница (дефолтный респаун), полицейский участок (спавн копов + тюрьма), склад (точка А доставок).
- Жилые кварталы: ~8 зданий, в каждом 1–2 квартиры для аренды.
- Окраины: точки Б доставки (магазин, заправка, порт) — маршруты через весь город.
- Парковки: ~15 машин по городу.

**Визуал:** low-poly из примитивов Three.js (здания — цветные боксы, машины — бокс+кабина+4 колеса, персонаж — капсула с головой). Цветовой код: копы — синие, розыскные — красный маркер, квартиры — табличка у двери. Освещение: directional + ambient. Никаких внешних ассетов.

**Коллизии:** статичные AABB зданий и границ карты, единый конфиг в `shared/`. Игроки и машины между собой не сталкиваются (упрощение MVP).

**UI клиента (HTML/CSS поверх canvas):** HUD (HP, наличные, сейф), экран выбора роли, подсказки («E — сесть в машину»), окно аренды у двери, окно сейфа, объявление о розыске, таймер тюрьмы.

## 6. Данные, ошибки, тестирование

### 6.1 Потоки данных

- **Realtime (память комнаты):** позиции, HP, состояние машин, розыск, тюрьма — в БД не пишутся.
- **Персистентные (SQLite, `better-sqlite3`):** аккаунт по нику, баланс (наличные + сейф), аренда (id квартиры + срок оплаты), суммарная статистика. Запись при изменении с дебаунсом 5 сек и при дисконнекте; чтение один раз при входе.
- **Конфиг (`shared/`):** карта, цены, урон, таймеры — константы, общие для сервера и клиента.

### 6.2 Обработка ошибок

- Дисконнект клиента → сервер держит слот 10 сек (переподключение), затем удаляет; его машина остаётся пустой.
- Исключение в серверной системе ловится и логируется, комната не падает.
- Валидация ввода на сервере: скорость движения, дистанция удара/ареста, cooldown действий; невалидное игнорируется.
- SQLite в WAL-режиме; сбой записи → ретрай, худший случай — откат к состоянию ≤5 сек назад.
- Комната полна (>100) → клиенту отказ «сервер полон».

### 6.3 Тестирование

- **Юнит-тесты (Vitest):** серверные системы в изоляции — бой, экономика, розыск/арест. Чистая логика без сети.
- **Интеграционный:** тестовый клиент подключается к комнате; спавн, движение, вход в машину, арест.
- **Нагрузочный:** `@colyseus/loadtest`, 100 ботов ходят/ездят; замер CPU/памяти и времени тика.
- **Ручной:** чек-лист прохождения всех механик в браузере.

## 7. Что НЕ входит в MVP

- Стрельба и арсенал оружия, NPC-полиция, интерьеры квартир, чат, звук, мобильные устройства, несколько серверов/шардирование, покупка (не аренда) недвижимости, столкновения игроков/машин между собой.
