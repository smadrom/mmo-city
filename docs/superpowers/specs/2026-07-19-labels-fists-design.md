# Этап «Подписи и кулаки» — дизайн-документ

Дата: 2026-07-19
Статус: утверждён пользователем (дизайн представлен в диалоге, ответ «Делаем»)
Предшественники: `2026-07-17-mmo-real-life-mvp-design.md`, `2026-07-18-arsenal-design.md`, `2026-07-19-chat-design.md`

## 1. Обзор

Две косметические доработки клиента, обе «дёшево» (без сервера, без схемы, без протокола):

1. **Названия зданий и значимых точек** — сейчас город безымянный, точки интереса различимы только цветом круга на земле. Добавляем парящие текстовые спрайты.
2. **Кулаки** — два простых шарика по бокам персонажа, без привязки к телу и без анимации. Визуальный маркер «руки свободны» (ближний бой кулаками уже есть: `PUNCH_*` в конфиге).

## 2. Решения, принятые на брейншторме

| Вопрос | Решение |
|---|---|
| Каким объектам названия | Всем значимым: здания по kind (`Больница`, `Полиция`, `Склад`, `Жилой дом`) + точки (`Оружейный магазин`, `Магазин`, `Заправка`, `Порт`) |
| Техника подписей | Canvas → THREE.Sprite (тот же приём, что ники над игроками в `avatars.ts`), НЕ HTML-оверлей и НЕ текстуры на крышах |
| Кому кулаки | Всем игрокам; видны только пешим и без оружия (`mode !== 'car' && !p.weapon`); при смерти скрыты вместе с группой |
| Анимация кулаков | Нет (YAGNI) — статично висят по бокам |

## 3. Подписи (client/src/world.ts)

- Хелпер `makeTextSprite(text: string): THREE.Sprite` — canvas 512×128, полупрозрачный чёрный фон, белый текст (как `makeNameLabel` в avatars.ts, но крупнее); `sprite.scale.set(10, 2.5, 1)`.
- Здания: подпись над крышей, `position.set(b.x, b.h + 3, b.z)`. Текст по `b.kind`: hospital → `Больница`, police → `Полиция`, warehouse → `Склад`, house → `Жилой дом`.
- Точки на земле (высота ~6 м):
  - `Оружейный магазин` → `map.gunShop`;
  - deliveryTargets по id: shop → `Магазин`, gas → `Заправка`, port → `Порт`.
- Итого ~20 спрайтов, статика, нулевая стоимость на кадр. Затухание по дистанции не делаем (туман уже режет дальность).

## 4. Кулаки (client/src/avatars.ts)

- `makePlayerMesh`: два `THREE.Mesh(SphereGeometry(0.18, 8, 6), MeshLambertMaterial(0xffcc99))` (цвет кожи, как голова) в группе игрока на `(±0.55, 1.2, -0.15)`. Интерфейс `PlayerMesh` += `fistL`, `fistR`.
- В `update()`: `fistL.visible = fistR.visible = onFoot && !p.weapon` — прячутся в машине и с любым оружием (бита/пистолет/винтовка), пешком без оружия — видны. При `mode === 'dead'` вся группа уже скрыта.

## 5. Тестирование

Клиентских автотестов в проекте нет (тесты — shared + server). Проверка:

1. `npm run build -w client` — тайпчек/сборка зелёная.
2. Ручная проверка на localhost: подписи читаются, кулаки видны пешком без оружия, прячутся в машине и с оружием (купить биту в оружейном — кулаки исчезают).

## 6. Вне рамок

- Анимация замаха при ударе.
- Подписи квартирам/парковкам, скрытие подписей по дистанции, локализация.
- Затронутые файлы: только `client/src/world.ts` и `client/src/avatars.ts`. Сервер, shared и схема не меняются.
