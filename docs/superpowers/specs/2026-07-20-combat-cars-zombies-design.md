# Этап «Бой, машины и зомби» — дизайн

Дата: 2026-07-20. Статус: утверждено пользователем (брейншторм в сессии).

## Контекст и цели

По итогам живой игры: урон и атаки не видны, машины «пластилиновые» (нет колёс-руля, сквозь людей и друг друга), диалог магазина не кликается под pointer lock, баннеры розыска/груза маскируют друг друга. Плюс хотелки: прицел, пикапы оружия на карте, живые противники (зомби), безопасные зоны у больницы и полиции.

Цели этапа:

1. Бой читается: цифры урона, HP-полоски, анимация замаха/отдачи/вспышки, прицел.
2. Машины: рулящие/крутящиеся колёса, наезд с уроном и отбросом, таран с разталкиванием.
3. Мир живее: пикапы оружия/патронов с респауном, ~20 серверных NPC-зомби, безопасные зоны (больница + полиция) без PvP и зомби.
4. Баг-фиксы: pointer lock в диалогах, многострочные баннеры, русские имена целей доставки.

Не входит (YAGNI): телефон с приложениями (отдельный этап), «физика 2.0» (бэклог), урон водителям при таране, дроп с зомби, патфайндинг зомби (скользят вдоль стен через `moveCircle`), визуальные повреждения машин.

## Архитектура

Сервер остаётся авторитетным; новые знания клиент получает двумя каналами: события-broadcast (`hit`, `swing`, как существующий `shot`) и схему состояния (`Car.steer`, `state.pickups`, зомби как `Player` с `role='zombie'`). Клиент — только визуал и ввод. Зомби — серверные NPC, переиспользующие общие системы (`tickMovement`, `handleAttack`, `tickRespawn`) через поле `role`; нагрузочные боты в `server/loadtest` не меняются.

## Константы (shared/src/config.ts)

```ts
export const PICKUP_RESPAWN_MS = 30_000;
export const PICKUP_RADIUS = 1.5;

export const ZOMBIE_COUNT = 20;
export const ZOMBIE_HP = 60;
export const ZOMBIE_SPEED = 4.5;      // между шагом (5 нет — 4.5) и спринтом 8: убежать можно
export const ZOMBIE_DAMAGE = 10;
export const ZOMBIE_AGGRO_DIST = 25;
export const ZOMBIE_RESPAWN_MS = 5000; // труп лежит, потом воскресает на точке спавна

export const RUNOVER_MIN_SPEED = 4;    // ниже — толчок без урона
export const RUNOVER_DAMAGE_K = 3;     // урон = round(|speed| * K), макс 60 при 20 м/с
export const RUNOVER_KNOCKBACK_K = 0.5;// отброс = |speed| * K, кап 6 м
export const RUNOVER_REPEAT_MS = 500;  // не чаще раза в 500 мс по одной жертве
export const CAR_CRASH_SPEED_KEEP = 0.3; // множитель скорости обеих машин при таране
```

`ZOMBIE_SPEED = 4.5` — чуть медленнее шага игрока (5), чтобы можно было отойти; корректируется по ощущениям.

## Сервер

### События урона (combat.ts)

`handleAttack` меняет контракт: возвращает `AttackResult { shot: Shot | null; swing: boolean; hits: Hit[] }`, где `Hit { victim: string; damage: number; x: number; z: number }`.

- `swing: true` — ближний замах принят (кулдаун прошёл), независимо от попадания. Раньше промах возвращал `null` молча.
- `hits` — по записи на каждое нанесение урона (melee и ranged; ranged сейчас отдаёт урон без числа).
- Урон кулаков зомби: `damage = w ? w.damage : (a.role === 'zombie' ? ZOMBIE_DAMAGE : PUNCH_DAMAGE)`; дальность/кулдаун общие с кулаками (`PUNCH_RANGE`, `PUNCH_COOLDOWN_MS`).
- Безопасные зоны: жертва внутри любой зоны из `map.safeZones` пропускается при выборе цели (новый параметр `safeZones: AABB[]`; хелпер `pointInAABB` в shared/physics). Атакующий внутри зоны также не может атаковать — нет кемпингу из зоны.

Комната по результату шлёт: `shot` (как раньше), `swing { player }` при `swing`, `hit` по каждому элементу `hits`.

`killPlayer`: если жертва `role === 'zombie'` — убийце `kills++`, но розыск (`wantedUntil`) НЕ выставляется.

### Наезд и таран (vehicles.ts)

`tickVehicles` возвращает `Hit[]` (комната бродкастит каждый как `hit`), сигнатура += `safeZones: AABB[]`.

- **Наезд**: для машины с водителем проверяются все `mode='foot'` (включая зомби) в радиусе `CAR_RADIUS + PLAYER_RADIUS`, кроме водителя и вне безопасных зон:
  - `|speed| > RUNOVER_MIN_SPEED`: если `now - rt.lastDamageAt >= RUNOVER_REPEAT_MS` — урон `round(|speed| * RUNOVER_DAMAGE_K)`, `rt.lastDamageAt = now`, hit-событие; смерть → `killPlayer(driverId)` (зомби-жертва — без розыска). В любом контакте — отброс `min(6, |speed| * RUNOVER_KNOCKBACK_K)` по нормали от машины через `moveCircle` (коллизии зданий сохраняются).
  - `|speed| <= RUNOVER_MIN_SPEED`: только лёгкий отброс (половинный), без урона.
- **Таран**: после движения всех машин — попарная проверка (15 машин, O(n²) тривиально). Перекрытие `dist < 2 * CAR_RADIUS` → каждую сдвинуть по линии центров на половину перекрытия (с клампом границ карты), обеим `speed *= CAR_CRASH_SPEED_KEEP`.
- **Steer**: вычисленный `steer` (−1/0/1) пишется в `car.steer` каждый тик (без водителя — 0).

Схема: `Car` += `@type('number') steer = 0`.

### Пикапы (новая система pickups.ts)

- Схема: `Pickup { id, kind: string, x, z, active: boolean }`, `state.pickups: MapSchema<Pickup>`. `kind`: `'bat' | 'pistol' | 'rifle' | 'ammo'`.
- Карта: `map.pickupSpots: Point[]` — 10 точек по кварталам у дорог (у больницы/полиции — вне безопасных зон, у склада, магазина, порта, заправки, пары домов, кладбища).
- `onCreate`: пикап на каждой точке со случайным видом (равновероятно из 4).
- `tickPickups(state, map, now)`: активный пикап + живой `mode='foot'` не-зомби в `PICKUP_RADIUS` → применить, деактивировать, серверный `respawnAt = now + PICKUP_RESPAWN_MS`. Эффекты: `ammo` → `ammo = min(AMMO_MAX, ammo + AMMO_PACK_SIZE)`; оружие → `p.weapon = kind` (замена без возврата, как покупка), ranged-оружие дополнительно даёт `+AMMO_PACK_SIZE` патронов (кап `AMMO_MAX`). Истёк `respawnAt` → `active = true`, новый случайный вид.

### Зомби (новая система zombies.ts)

- Зомби — записи в `state.players` с `role = 'zombie'`, `name = 'Зомби'`, id `z0..z{N-1}`; у каждого свой runtime (кулдаун атаки, lastDamageAt). Создаются в `onCreate`, не клиенты (слоты `maxClients` не занимают).
- Карта: `map.zombieSpawns: Point[]` — 6 точек: кладбище (новая зона, угол карты (180, 180)) + разброс по краям.
- `tickZombies(state, runtimes, map, colliders, dt, now)` → возвращает `AttackResult[]` для broadcast:
  - Цель: ближайший живой не-зомби игрок `mode='foot'` вне безопасных зон в `ZOMBIE_AGGRO_DIST`. Есть цель → `rt.input = { up: true, sprint: false, rotY: atan2(-(dx), -(dz)) }` (конвенция forward = (−sin, −cos)); движение выполняет общий `tickMovement`. В упоре (`PUNCH_RANGE`) → общий `handleAttack` (кулдаун через runtime), результат собирается для broadcast.
  - Нет цели → блуждание: раз в ~3 сек (по runtime-полю) случайный `rotY`, `up: true`.
  - Зомби не входит в безопасные зоны: после движения — откат позиции на тик назад, если оказался внутри зоны.
  - Скорость: `stepFoot` получает опциональный параметр скорости (default `PLAYER_SPEED`); зомби передают `ZOMBIE_SPEED`. Клиентское предсказание не меняется (игрок ходит со стандартной скоростью).
- Респаун: `tickRespawn` ветвится по роли: зомби после `ZOMBIE_RESPAWN_MS` воскресает на случайной точке из `map.zombieSpawns` с `hp = ZOMBIE_HP` (игроки — как раньше, `MAX_HP` у двери/квартиры).
- Исключения по роли: `savePlayer` пропускает зомби (иначе «Зомби» осядут в БД); зарплата (только `cop`) и аренда (нет `apt`) не тронуты; арест невозможен (зомби никогда `wanted`); чат/магазин/доставка зомби недоступны (нет клиента), но подбор пикапов явно запрещён (см. выше).

### Комната (CityRoom.ts)

- Создание зомби и пикапов в `onCreate`; в `tick` — `tickZombies` и `tickPickups`; результаты атак зомби и `Hit[]` из `tickVehicles` — broadcast `swing`/`hit`.
- `savePlayer`: `if (p.role === 'zombie') return;`
- Вызовы `handleAttack`/`tickVehicles` — с новым параметром `safeZones`.

## Клиент

### Бой

- **Цифры урона** (effects.ts): по `hit` — canvas-спрайт `−{damage}` на (x, z), всплывает ~0.5 м и тает за 700 мс (жизненный цикл как у tracer'ов, с dispose).
- **HP-полоска** (avatars.ts): под ником два тонких спрайта (тёмный фон + цветная полоска, ширина 1.2): `scale.x = hp / MAX_HP`, цвет зелёный→красный. Видна над чужими живыми пешеходами (себе — HUD, в машине/мертв — скрыта).
- **Анимации** (avatars.ts + effects.ts): `effects` ловит `swing`/`shot` и вызывает `avatars.playSwing(id)` / `playRecoil(id)`; прогресс — в `update()`. Замах: правая рука (кулак или бита) вперёд-назад за 150 мс (`sin` по прогрессу). Отдача: ствол назад ~80 мс + вспышка-спрайт у дула на 60 мс (дочерний к `gun`).
- **Меш биты**: коричневый брусок в правой руке, `visible = onFoot && weapon === 'bat'` (кулаки по-прежнему только без оружия).
- **Прицел** (ui.ts + CSS): точка-крестик по центру, виден только при активном pointer lock, закрытых чате/диалогах и живом игроке.

### Машины

- Колёса заворачиваются в `Group`: передним `rotation.y = car.steer * 0.5`, всем колёсам вращение вокруг оси со знаком `speed` (угловая скорость `speed / r`). Интерполяция не трогается.

### Мир

- **Пикапы** (новый pickups.ts): меши по `state.pickups` (`onAdd`/`onRemove`, `visible = active`): бита — коричневый брусок, пистолет/винтовка — тёмные бруски разной длины, патроны — зелёная коробка. Медленное вращение + лёгкое парение (`sin` по времени).
- **Зомби**: роль `zombie` в `makeNameLabel`/цвете тела — зелёная капсула, табличка «Зомби»; остальное работает через общий код (кулаки видны, HP-полоска видна).
- **Забор** (world.ts): по периметру каждой `safeZone` — низкие секции забора (h 1.2) с воротами со стороны дороги + спрайт-подпись «Безопасная зона». Кладбище — тёмный участок земли с подписью «Кладбище» (по первой точке `zombieSpawns`).

### Баг-фиксы

- **Pointer lock**: по `openShop`/`openSafe` — `document.exitPointerLock()` (как у чата); обратный захват — существующим кликом по canvas.
- **Баннеры**: строки собираются массивом (тюрьма, розыск, груз, смерть) и `join('\n')` — все активные одновременно. `TARGET_LABELS` переезжает в `shared/map.ts` (баннер показывает «Порт» вместо `port`, world.ts импортирует оттуда же).

## Изменение схемы и деплой

Схема меняется: `Car.steer`, `Pickup`/`state.pickups`, `role='zombie'`. Клиент и сервер выкатываются только вместе (правило уже зафиксировано в плане деплоя).

## Тестирование

Сервер (TDD, vitest):

- combat: `swing` при промахе/попадании, `hits` с уроном и координатами, урон по жертве в безопасной зоне заблокирован (melee и ranged), убийство зомби — kills без розыска, зомби бьёт `ZOMBIE_DAMAGE`.
- vehicles: наезд — урон по скорости/отброс/кулдаун 500 мс/розыск при смерти; толчок без урона на малой скорости; наезд на зомби без розыска; таран — машины разведены, скорости погашены; `steer` пишется в схему.
- zombies: агро в радиусе (input.rotY/up на цель), атака в упоре с событием, игнор цели в безопасной зоне, откат при входе в зону, воскрешение на `zombieSpawns` с `ZOMBIE_HP`, `savePlayer` не пишет зомби.
- pickups: подбор оружия/патронов, кап `AMMO_MAX`, деактивация и респаун по таймеру со сменой вида, зомби/мёртвый/в машине не подбирает.
- shared: `stepFoot` с кастомной скоростью, `pointInAABB`.

Клиент: `npm run build -w client` зелёный; README «Ручной чек-лист» дополняется пунктами: цифры урона, HP-полоска, замах/отдача/вспышка, колёса, прицел, диалоги кликаются сразу, два баннера одновременно, наезд/таран, пикапы, зомби, безопасные зоны, забор.

Ручная проверка вдвоём по сети — по обновлённому чек-листу.
