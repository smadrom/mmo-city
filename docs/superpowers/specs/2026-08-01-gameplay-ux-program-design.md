# Программа улучшений «играбельность+» — дизайн

> Снято с `main` после P0-харденинга (задачи 1–8 плана `2026-07-24-p0-launch-hardening.md`). Основание: полное ревью кодовой базы 2026-08-01 (баланс, UX, i18n, экраны, мобилка).

**Цель:** поднять интерес и качество игры до состояния «не стыдно открыть»: честная экономика, метагейм, локализация RU/EN, звуки, реконнект, адаптивная вёрстка, базовое тач-управление.

**Рамки:** без новых зависимостей, без смены стека. Коммиты — conventional на русском. Тесты зелёные после каждой задачи (`npm test`, `npm run typecheck`). Декомпозиция: 7 вех (M1–M7), каждая — самостоятельный вертикальный ломтик.

## M1. Баланс (S-пак)

Все числа — `shared/src/config.ts`.

1. **Награда доставки от дистанции.** Замена `DELIVERY_REWARD=100`: `DELIVERY_REWARD_BASE=60`, `DELIVERY_REWARD_PER_M=0.4`. Награда = `round(60 + 0.4 × dist(склад, точка))`. Считается в `economy.ts` при сдаче (`tickDelivery`) общей функцией `deliveryReward(map, targetId)` — клиент считает тем же импортом для отображения (схема не меняется). Ориентир: Магазин ~141$, Заправка ~134$, Порт ~209$.
2. **Кулдаун на заказ после отказа/просрочки** — 30 сек (`JOB_RETRY_COOLDOWN_MS`). `Runtime.nextJobAt`; ставится в `tryDropJob` и в `tickDelivery` при просрочке; проверяется в `tryTakeJob`/`tryStartDelivery`. `jobResult error: 'job_cooldown'`. Не персистится.
3. **`ARREST_BONUS` 50 → 150.** Коп перестаёт быть худшей ролью.
4. **Дроп с зомби.** В `killPlayer`: жертва-зомби, убийца не зомби → `spawnCashDrop(10 + floor(rand×20))` на месте смерти. Кладбище становится PvE-фарм-зоной.
5. **Пистолет: damage 15 → 25** (62.5 DPS — между битой 44 и винтовкой 100, с дальностью 40 м).
6. **Дроп оружия при смерти.** `killPlayer`: если у жертвы (не зомби) было оружие — пикап `kind=<оружие>` на месте смерти (id `wpn-<victimId>-<now>`), без runtime-записи: в `tickPickups` пикап без runtime после подбора удаляется (как cash), а не респаунится.

Тесты: награда от дистанции (магазин < порт), кулдаун заказа, дроп с зомби (количество в диапазоне), дроп оружия (пикап появляется, подбирается, исчезает).

## M2. UX (S-пак)

1. **HP-бар** в HUD: полоска (зелёная → красная) + число; при ranged-оружии крупный счётчик патронов отдельной строкой. `ui.ts`, `index.html`, `style.css`.
2. **Блок ввода в диалогах** магазина/сейфа: `openSafe`/`openShop` → `input.setBlocked(true)`; закрытие (кнопка, Esc, смерть/машина) → `false`. UI уже держит `input`.
3. **`renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`** — чёткость на Retina/мобильных.
4. **Resize полной карты:** при открытой карте ресайз окна → пересчитать canvas и перерисовать (`fullmap.ts`).
5. **Экран смерти:** полноэкранный `#deathOverlay` («Вы погибли», обратный отсчёт до респавна) вместо строки в баннере; скрывается при `mode !== 'dead'`.

## M3. Метагейм

1. **Kill feed.** Сервер шлёт broadcast `feed { kind: 'kill'|'bounty'|'arrest', a, b }` (ники). Источники: `killPlayer` (убийство игрока игроком; `bounty` — если жертва была в розыске), арест в `tickPolice`. Клиент: правый верхний угол, до 5 строк, затухание 5 сек. `killPlayer` возвращает описание события (для feed/bounty), вызовы в `combat.ts`/`vehicles.ts` пробрасывают наружу через `AttackResult`.
2. **Bounty.** `BOUNTY_REWARD=25`. В `killPlayer`: жертва в розыске (`wantedUntil > now`), убийца не зомби → убийце +25$ и розыск НЕ назначается (праведное убийство).
3. **Лидерборд.** Телефон, 4-е приложение «Рейтинг». `db.topByKills(10)` → `SELECT name, kills, deaths FROM players ORDER BY kills DESC LIMIT 10`. Сообщения: `leaderboardReq` (кулдаун `SMS_HISTORY_COOLDOWN_MS`, поле `rt.lastLbAt`) → `leaderboard { items }`. Клиент: список «ник — убийства/смерти».

Тесты: bounty (награда и отсутствие розыска), feed-сообщения при убийстве/аресте, topByKills порядок/лимит.

## M4. Локализация RU/EN

- `client/src/i18n/`: `ru.ts`, `en.ts` — плоские словари `id → строка` (плейсхолдеры `{name}`); `index.ts`: `t(id, params?)`, `getLang()`, `setLang()` (localStorage `lang`; дефолт — `navigator.language` начинается с `ru` → ru, иначе en).
- Мигрируются все пользовательские строки клиента (~100): `index.html` (перерисовка статики через `data-i18n` атрибуты), `main.ts`, `ui.ts`, `phone.ts`, `avatars.ts`, `world.ts` (3D-таблички), `minimap.ts`/`fullmap.ts` (POI), `pickups.ts`. `TARGET_LABELS` из shared заменяется ключами i18n на клиенте (`target.shop` и т.п.); в shared остаются только id.
- **Сервер отдаёт коды, не тексты:** `notice { text }` → `notice { code: 'muted', until }` — текст собирает клиент. Имя зомби на табличке клиент рисует из `t('zombie')` по `role==='zombie'` (серверное `z.name` не трогаем).
- Переключатель языка на экране входа (RU/EN кнопки).
- **`PROTOCOL_VERSION` → 3** (изменился формат `notice`).
- Тесты: серверный тест мута обновляется на `code: 'muted'`; unit-тест `t()` (fallback на ru при пропущенном ключе — нет, строго: отсутствующий ключ → сам ключ, чтобы было видно в dev).

## M5. Звуки (WebAudio, без ассетов)

Расширение `effects.ts`: синтез osc+gain (как существующий `click()`).

- `shot` (есть), `hitDealt` (короткий высокий блип — я попал: из `hit` где attacker = я… attacker в `hit` не приходит → добавить `attacker` в broadcast `hit` в `broadcastAttack`), `hitTaken` (низкий глухой — по мне, уже есть виньетка), `picked` (подбор пикапа: сервер — `tickPickups` возвращает список подборов, CityRoom шлёт адресно `picked { kind, amount }`), `cashIn` (сдача груза: `tickDelivery` возвращает завершённые заказы, CityRoom шлёт адресно `delivered { reward }`; заодно тост «+N$» на клиенте), `death` (нисходящий тон при своей смерти — из state-change mode → dead).
- Mute-глушилка: клавиша N, localStorage `mute`.

Тесты: сервер — `picked`/`delivered` сообщения; клиент — typecheck + ручная проверка.

## M6. Реконнект

- Сервер уже держит окно `allowReconnection(client, 10)` и морозит призрака — не трогаем.
- Клиент `net.ts`/`main.ts`: кэшировать `room.reconnectionToken`; `onLeave` (код не 4000 — не кик/не consented) → оверлей «Соединение потеряно…», цикл `client.reconnect(token)` каждую секунду до ~10 сек; успех — подмена room и продолжение без перезагрузки (переподписка обработчиков — вся подписка в `bootGame`, вынести в функцию, принимающую room); неуспех/кик (4000) — `location.reload()` как сейчас.
- Проверить API `client.reconnect` по типам colyseus.js 0.16 в `node_modules` при реализации.

## M7. Адаптив CSS + тач-управление

1. **CSS:** переменные, `clamp()`; брейкпоинт ≤700px: миникарта 140px, телефон — полноэкранный оверлей, чат 60vw, уменьшенные шрифты HUD. Конфликт телефон/миникарта (нужно ≥560px ширины) убирается оверлеем.
2. **Тач-ввод** (`client/src/touch.ts`): показывается при `ontouchstart in window`. Левый виртуальный джойстик → `up/down/left/right` (дедзона) + `sprint` при отклонении >85%; свайп по правой половине экрана → `yaw`; кнопки: атака, E, телефон, карта. Pointer lock на тачах не запрашиваем. `touch-action: none` на canvas.
3. **Полная карта на таче:** drag = пан, pinch = зум.

## Порядок и проверка

`M1 → M2 → M3 → M5 → M4 → M6 → M7` (i18n после фич — новые строки сразу кладём в словари; реконнект и тач — самые рискованные, в конец).

- После каждой задачи: `npm test` + `npm run typecheck` из корня.
- Сквозной ручной smoke в конце: два окна, доставка с новой наградой, дроп оружия/зомби, feed, лидерборд, EN-локаль, обрыв сети → реконнект, эмуляция тача в DevTools.
- Коммит на задачу, conventional на русском, без AI-атрибуции.
