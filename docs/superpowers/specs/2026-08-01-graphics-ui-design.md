# Графика и UI (S+M паки) — дизайн

> Снято с `main` после программы «играбельность+» (26+ коммитов, всё зелёное). Основание: ревью графики/UI 2026-08-01 (world.ts/camera.ts/avatars.ts/effects.ts/ui.ts прочитаны).

**Цель:** поднять визуальное качество и информативность: тени, окна, зум, хитмаркер, метрика, системные сообщения (S-пак); коллизия камеры, инстансинг статики, день/ночь, меню настроек, онбординг, Tab-список (M-пак).

**Рамки:** без новых зависимостей (`three/examples/jsm/utils/BufferGeometryUtils.js` — часть пакета three, не зависимость). Коммиты conventional на русском. Гейты после каждой задачи: `npm run typecheck` (+`npm test` при серверных правках). Новые пользовательские строки — только через i18n-словари ru/en.

## S-пак

### S1. Тени
`renderer.shadowMap.enabled = true` (PCFSoft). Солнце (`world.ts:35`): `castShadow`, ортокамера ±220, mapSize 2048, `scene.add(sun.target)`. Здания и машины/тела+головы игроков — `castShadow`; земля — `receiveShadow`. Переключение в рантайме (меню настроек M4): `renderer.shadowMap.enabled` + `traverse` c `material.needsUpdate = true`.

### S2. Окна на зданиях
Canvas-текстура сетки окон (6×10, тёмные + ~15% «горящих»), генерируется один раз, применяется к боковым граням жилых домов (`kind==='house'`) через material-массив BoxGeometry (индексы 0,1,4,5 — текстура; 2,3 — однотон). Спецздания (больница/полиция/склад) — однотонные, как сейчас.

### S3. Зум камеры + FOV прицела
`CAM_DIST` 4..12 колёсиком (гард: не fullmap/не phone/не печать). Прицел (RMB, `input.aiming`): FOV 70 → 55 с плавным лерпом (`dt*10`), иначе обратно. `camera.ts` принимает dist.

### S4. Хитмаркер + направление урона
Хитмаркер: `#hitmarker` (× в центре), показ 150 мс при `hit` где attacker=я, victim≠я (точка в `effects.onHit` — там уже звук). Направление урона: при victim=я — красный дуговой клин у центра экрана, повёрнутый на угол атакующего (позиция из state по `attacker`, относительно `me.rotY`), 400 мс затухание.

### S5. F3-метрика + ping
Сервер: `onMessage('ping', (client, data) => client.send('pong', data))` + интеграционный тест. **`PROTOCOL_VERSION` → 4** (новая пара сообщений). Клиент: `#debug` оверлей по F3 (гард печати): FPS (счёт кадров за 500 мс) и RTT (ping каждые 2 с, когда видимо). Текст языконейтральный (`62 FPS · 38 ms`), без ключей. Обработчик `pong` — в `bindRoomMessages` (реконнект-безопасно).

### S6. Системные сообщения в чат
Сервер: broadcast `sys { code: 'join'|'leave', name }` — в `onJoin` (после успеха) и `removePlayer` (фактический выход); «тихий» режим при вытеснении призрака (`removePlayer(id, silent)`) — иначе реконнект спамит парой leave+join. Клиент `ui.bind`: рендер в чат курсивом без двоеточия, текст `t('sys.join'|'sys.leave', { name })` (ключи ru/en). Интеграционный тест.

## M-пак

### M1. Коллизия камеры
`updateCamera(camera, x, z, yaw, dist, colliders)`: 2D-сегмент (игрок → желаемая позиция камеры) через `segmentAABBEnterT` по коллайдерам зданий; при пересечении dist укорачивается до точки входа −0.5 (мин 1.5). Коллайдеры из `map.buildings` (считаются один раз в main).

### M2. Инстансинг статики
Штрихи разметки (~400 мешей) и сегменты забора (~250) — в merged `BufferGeometry` по одному мешу на тип (`mergeGeometries` из `three/examples/jsm/utils/BufferGeometryUtils.js`). Дороги/тротуары (18 мешей) и здания (16) не трогаем.

### M3. День/ночь
Цикл 10 мин: `buildWorld` возвращает `{ map, fx }` (`fx.update(now)`). Лерп: sun.intensity 0.25..1.2, ambient 0.25..0.55, небо/туман `0x0a0a2e ↔ 0x87ceeb`, цвет солнца `0x8899ff ↔ 0xffffff`. Старт — день (фазовый сдвиг). main дергает `fx.update` в цикле; при выключенных тенях (настройки) цвета продолжают работать.

### M4. Меню настроек (Esc)
Оверлей `#settings`: громкость (слайдер → `effects.setVolume(v)`, множитель в `tone()`, localStorage `vol`), mute (существующий N — дублировать чекбоксом), язык RU/EN (`setLang`+`applyStatic`, тост `settings.langNote` — 3D-подписи до перезахода), качество: низкое = pixelRatio 1 + тени выкл, высокое = pixelRatio min(dpr,2) + тени вкл. Esc-диспетчер централизуется в main: phone → fullmap → диалоги → settings (Esc-ветки из phone/fullmap/ui убираются, toggle по P/M остаются). При открытом меню — `input.setBlocked(true)`.

### M5. Онбординг
Первый вход (localStorage `seenIntro`): три тоста с задержками 1/5/9 с — `hint.move` (WASD/мышь/зум), `hint.car` (машина и работа), `hint.wanted` (розыск и награда). Ключи ru/en.

### M6. Список игроков (Tab)
`tablist.ts`: hold-Tab (preventDefault, не печать) — оверлей со списком из `state.players` (без зомби), сортировка: копы первыми, затем по нику; строка = ник + роль (`role.*` ключи). Обновление раз в сек, пока открыт. Заголовок `tab.title`.
