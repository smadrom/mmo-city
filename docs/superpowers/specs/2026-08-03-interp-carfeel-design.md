# Пакет «интерполяция + ощущения машины» — дизайн

> Основание: репорт с прода — чужие движения/интерполяция «не по-нормальному», машина унылая. Решение: два пакета за один заход.

## A. Интерполяция (client-only, `avatars.ts`)

1. **Адаптивный джиттер-буфер** вместо фиксированных `INTERP_DELAY_MS = 120`: трекинг времени прихода патчей (последние ~10 интервалов), `delay = clamp(медиана × 1.5 + 30, 60, 250)` мс. На хорошем канале чужие ближе к realtime, на плохом — стабильно.
2. **Экстраполяция при разрывах:** когда renderTime свежее последнего снапа — двигаем по скорости из последних двух снапов, кап +250 мс (заморозка дальше).
3. **Catmull-Rom** по 4 снапам для позиции (вместо линейного лерпа — плавные дуги поворотов), анти-overshoot: результат зажимаем в круг `|p2| ≤ 1.5·|p1p2|`. rotY — прежний lerpAngle.

## B. Ощущения машины

1. **stepCar (shared, сервер+клиент синхронно):**
   - **Нитро на Shift:** `inp.sprint` → лимит скорости ×1.5 (`CAR_NITRO_SPEED_MULT`), разгон ×1.3 (`CAR_NITRO_ACCEL_MULT`). `CAR_MAX_SPEED` 20 → 26 (с нитро 39).
   - **Столкновение:** не полный стоп, а отскок `speed = -speed × 0.25` (`CAR_CRASH_BOUNCE`). Обновить тесты vehicles/physics.
2. **Динамическая камера (client):** в машине дистанция `camDist + |speed|/CAR_MAX_SPEED × 3`; пружинный лаг позиции камеры (lerp dt·5 в машине, dt·10 пешком); roll камеры по рулю `−steer × speed/MAX × 0.06` рад; тряска при резкой потере скорости (камера-shake с экспоненциальным затуханием, детект падения |speed| > 8 за патч).
3. **Звук (client, effects.ts):** мотор — зацикленный осциллятор (sawtooth, частота `40 + |speed|×3` Гц, gain по скорости), старт/стоп по смене mode; визг при жёстком торможении (down при |speed|>12); удар при детекте столкновения (резкий сброс скорости).
4. **Следы шин (client):** детект резкого торможения по серверным патчам (падение |speed| > 8 за интервал) для ВСЕХ машин — тёмная полоска-декаль (0.4×1.2, y=0.035) под машиной, затухание ~10 с, кап 200 штук (FIFO).

## Порядок
T1 интерполяция → T2 stepCar (нитро+отскок) → T3 камера → T4 звук+следы → T5 гейты/README/выкат. Гейты после каждой: typecheck (+`npm test` при shared/server правках). Без смены протокола (схема/сообщения не тронуты — bump не нужен).
